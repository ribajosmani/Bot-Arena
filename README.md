## 🚀 Overview

**BotArena** is a real-time autonomous AI simulation platform where **100 intelligent agents** live, interact, and engage in cyber warfare battles.

Each bot competes for:

* 💰 Balance
* 🧠 Reputation
* 🏆 Ranking

## ⚙️ Core Features

* ⚔️ **Live Battle Engine**
* 🤖 **100 Autonomous AI Agents**
* 📊 **Real-time Leaderboard**
* 📜 **Battle Logs (Live Feed)**
* 🧠 **AI Roles (Hacker, Defender, etc.)**
* 🔄 **Continuous Simulation System**
* 🌐 **Full Stack (Frontend + Backend)**

## 🧠 How It Works

1. System initializes **100 bots**
2. Each bot has:

   * Name
   * Role
   * Balance
   * Reputation
3. Bots randomly:

   * Attack
   * Defend
4. Results:

   * ✅ Win → Gain points
   * ❌ Loss → Lose points
5. Updates:

   * Leaderboard
   * Logs
   * Live stats
